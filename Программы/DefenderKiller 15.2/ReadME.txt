---------------------------- Описание DK ------------------------------
DefenderKiller - .bat файл для удаления / восстановления из копии Windows Defender.
В нем также можно удалить приложение Безопасность из Пуска и выполнить некоторые другие дополнительные действия по защитнику.

Windows 7 имеет ограниченную поддержку. Нежелательно использовать данный софт в Windows 7. На ней же не используется Unlocker , драйвер, не удаляется приложение Безопасность. 
Windows 8 не тестировалась, поведение DK в этой версиии мне неизвестно и никто не сообщал.
x32 поддержки нет. Есть старые версии на NNM, где эта "поддержка" еще была, можно найти, но не желательно использовать старые версии. Лучше использовать другое решение по защитнику для x32 систем.

-------------------------- Резервная копия перед удалением ------------------------------
Резервная копия не создается на Windows 7! То есть восстановить невозможно на этой версии. Лучше не использовать DK на этой Windows. Либо использовать на свой риск.

Во время первого удаления программа предложит вам создать резервную копию всего, что будет удалено ЭТОЙ (DK) программой.
Вы можете пропустить этот шаг или согласиться с созданием копии.
>>>>> Создание резервной копии ОБЯЗАТЕЛЬНО если Вы обновляете Windows.
В ином случае с удаленным защитником Центр Обновлений при установке обновления выдаст ошибку установки обновления. (Большая вероятность)

Резервная копия создается в корень диска с установленной Windows (диск C:\ или другая буква диска, если Вы ее изменили сами в процессе установки системы)
Позже, используя эту резервную копию, можно восстановить, что было удалено ЭТОЙ (DK) программой.
DK НЕ МОЖЕТ ПОЧИНИТЬ/ВОССТАНОВИТЬ ТО, ЧТО ВЫ САМИ УДАЛИЛИ СВОИМИ РУКАМИ/ДРУГИМИ ПРОГРАММАМИ ПО УДАЛЕНИЮ / ОТКЛЮЧЕНИЮ.

Не забывайте делать копию, это очень важно, если защитник Вам далее будет нужен. Читайте этот ReadMe файл, вдумчиво относитесь ко всему, что делайте этим софтом!

------------------------------  Драйвер Kernel [5] ------------------------------
Драйвер работает в режиме ядра (kernel).
Выполняет только две функции: Завершение процессов Защитника / Удаление из реестра разделов служб.

Для его использования необходимо отключить SecureBoot в BIOS. В ином случае не сможет запуститься.
Инструкция как отключить SecureBOOT - https://remontka.pro/secure-boot-disable/

Зачем нужен драйвер:
1. Вы выполнили удаление в DK
2. Вы выполнили перезагрузку после удаления и видите, что даже после перезапуска ПК какие-то службы имеют красный цвет (не смогли удалиться)
3. Вы используете драйвер, у которого есть максимальные привелегии ядра, который может "дочистить" не удаленные службы

Задача драйвера - подчистка! Как правило для таких служб/драйверов как WinDefend / MDCoreSvc / WdFilter и др.

Дополнительных действий данный драйвер не делает. Не останется нигде в системе. Удаляется сам после использования через DK.

------------------------------ Приложение Безопасность Windows в меню Пуск ------------------------------
Удаление приложения Безопасность в Пуске производится в пункте 4 >> 2
После удаления приложения "Безопасность Windows", Вы НЕ СМОЖЕТЕ зайти в настройки защитника ДАЖЕ после восстановления копии.
Восстановление приложения в DK не предусмотрено.
Удаляйте приложение ТОЛЬКО в том случае, если Вы точно не будете пользоваться защитником или знаете как восстановить системное приложение.
Сделать это можно в ASPS (AutoSettingsPS), отредактировав перед этим пресет его настроек.
Восстановление производится в ASPS здесь - [2 > 14]
