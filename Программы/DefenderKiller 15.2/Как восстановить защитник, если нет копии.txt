Если Вы выполнили удаление и не сделали копию и Вам потребовалось восстановить Defender, вот краткая инструкция как это можно сделать:

1. Скачивайте виртуальную машину (VMware / VirtualBox)
Ссылка на VMware - https://www.comss.ru/download/page.php?id=2110

2. Устанавливаете VMware / VirtualBox на Ваш ПК. Следуйте указаниям инсталятора в ходе установки.

3. Скачиваете ISO образ вашей версии Windows (Узнать какая у Вас версия - win + r > ввести winver)
Windows 10 ISO - https://www.comss.ru/page.php?id=12823
Windows 11 ISO - https://www.comss.ru/page.php?id=10053

4. Создаете Виртуальную машину в VMware или VirtualBox
4.1. Устанавливаете Windows с помощью ISO файла, который был скачан в пункте 3
Гайды, как создать виртуальную машину и как установить Windows можно найти на YouTube.

4.1. Для работоспособности DragDrop (перетаскивание из виртуальной машины к себе на ПК и наоборот) установить:
Для VMware - VMware Tools (будет предложено во время установки Windows)
Для VirtualBox - Extension (https://gb.ru/manualvirtualbox)

5. После установки Windows и дополнений из пункта 4.1, перекидываем папку с DK в виртуальную машину.
Начинаем выполнять удаление > будет предложение создание копии > соглашаемся на создание копии.
Копия сохраняется сюда - C:\WDefenderBackup
Перекидываем из виртуальной машины к себе на основной ПК папку с копией.

6. Восстанавливаем защитник из копии , которую получили с виртуальной машины
